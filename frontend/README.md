# Outfit Inventory — Frontend

Next.js (App Router) + TypeScript + Tailwind CSS. See the
[root README](../README.md) for how to run this alongside the backend.

## Structure

- `src/app/` — App Router pages (`(auth)/login`, `(auth)/signup`, `upload`,
  `wardrobe`)
- `src/components/` — shared UI components
- `src/lib/api.ts` — backend API base URL config
